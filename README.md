# 🎸 Rocknonym! — Points Edition

Classic rock meets brain teaser in this anagram puzzle game. Unscramble classic rock songs and bands, earn points, and spend them on hints!

## 🚀 How to Use

1. Clone or download the repository.
2. Open `index.html` in your browser.

## 🧠 Features

- 10 classic rock puzzles
- Case-insensitive input
- Confetti celebration 🎉
- Hint shop system with point costs

## 🌐 Deploy to GitHub Pages

1. Push to a GitHub repository.
2. Go to **Settings > Pages**.
3. Set source to `/root` on the `main` branch.

Enjoy the rock-n-roll brain workout!
